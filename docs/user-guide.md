# AI Price Monitor 使用说明

## 1. 主要功能

- 添加店铺并监控商品价格和库存变化。
- 自动或手动分类商品，方便筛选和比价。
- 记录商品历史价格，查看价格走势和历史最低价。

## 2. 添加店铺

### 2.1 手动添加

点击左侧的“添加店铺”，输入店铺链接。目前仅支持链动小铺（`pay.ldxp.cn`）。添加成功后，店铺会显示在店铺列表末尾。

![](assets/2026-07-26-00-03-13-PixPin_2026-07-26_00-02-17.webp)

### 2.2 从文件导入

1. 点击右上角的“设置”。
2. 找到“店铺导入导出”。
3. 点击“导入店铺列表”并选择文件。
4. 等待店铺信息刷新完成。若刷新长时间没有进展，可刷新页面后重试，或点击“全局刷新”。

如需店铺列表文件，可联系作者：QQ `2087629236`，邮箱 `kirk-yang@qq.com`。

![](assets/2026-07-26-00-22-10-PixPin_2026-07-26_00-21-18.webp)

完成店铺添加后，即可使用主要的监控、筛选和比价功能。

### 2.3 完整数据导入导出

设置中可以导入或导出店铺及其历史数据，适合备份数据或迁移到其他设备。历史数据会持续更新，如需现成数据也可以联系作者。

![](assets/2026-07-26-00-52-50-image.png)

## 3. 刷新机制

刷新任务的优先级为：单店铺刷新 > 全局刷新 > 定时刷新。

### 3.1 单店铺刷新

需要立即查看某个店铺的最新价格时，可点击该店铺的刷新按钮。刷新期间，店铺名旁会显示当前状态。

![](assets/2026-07-26-00-32-32-image.png)

### 3.2 全局刷新

点击“全局刷新”会按右侧店铺列表的顺序更新所有店铺。拖动店铺名可以调整顺序，优先关注的店铺建议放在前面。

每个店铺需要依次获取店铺信息、商品列表和商品详情。为降低请求过快导致访问受限的风险，全局刷新会控制请求频率，因此可能需要一些时间。

![](assets/2026-07-26-00-27-34-image.png)

### 3.3 定时刷新

- 随机刷新：在设定的时间范围内分散刷新任务，避免请求过于集中。
- 固定刷新：按设定的周期检查并刷新超时店铺，不建议将间隔设置得过短。

修改刷新设置后，请点击“保存设置”。

![](assets/2026-07-26-00-36-23-image.png)

## 4. 商品分类

### 4.1 分类结构

当前分类主要依赖本地规则，分为以下层级：

- 一级分类：GPT、Claude、Gemini、Grok 等产品系列。
- 二级分类：各产品系列下的具体套餐或类型。
- Plus 细分：针对 GPT Plus 的接码、开通方式和质保等属性进一步筛选。

![](assets/2026-07-26-00-41-34-image.png)

### 4.2 分类管理

在“设置 → 分类管理”中，可以添加和调整分类规则、修改分类顺序及控制分类是否显示。完善包含词和排除词可以提高自动分类的准确度。

![](assets/2026-07-26-00-45-12-image.png)

### 4.3 手动归类

点击商品卡片左上角的分类标签，可以手动修改商品分类。手动分类结果会被保留，不会被后续的自动分类覆盖。

![](assets/2026-07-26-00-47-20-PixPin_2026-07-26_00-47-03.webp)

### 4.4 包含与排除搜索

搜索支持同时设置包含词和排除词，可用于快速筛选符合条件的商品。

![](assets/2026-07-26-00-51-00-PixPin_2026-07-26_00-49-24.webp)
